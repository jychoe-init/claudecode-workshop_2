# M-FABLE51 — 관찰된 증상부터

확인일: 2026-10-04
근거: https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-1
확인할 섹션: 도입의 이전 Fable 프롬프트 호환 설명; Ask for user-facing progress updates; Formatting in chat.

- 이전 Fable 프롬프트가 잘 작동하면 그대로 유지한다. 문제가 관찰된 부분부터 조정한다.
- 긴 작업에서 필요한 진행 설명이 빠진 경우, 현재 있는 설명 억제 지시를 확인한다.
- 서식 억제 지시로 필요한 구조가 사라졌다면 해당 지시를 조정한다.
- 다른 모델의 ‘자기 검증 지시 삭제’ 권고를 이 모델의 일반 규칙이라고 주장하지 않는다.
