# M-OPUS55 — 용도와 증상에 따른 조정

확인일: 2026-10-04
근거: https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5
섹션: Calibrate effort; Thinking instructions in chat system prompts; Explore context in multi-app workflows; Mark pasted text in user messages.

- 잘 작동하는 기존 프롬프트는 유지하고 관찰한 증상에 맞게 조정한다.
- 채팅에서 생각을 과도하게 강제하는 일반 문구는 지연을 늘리는지 살핀다. 실제 작업의 테스트·근거·완료 조건과 구분한다.
- 여러 연결 앱에 필요한 정보가 흩어진 작업에는 관련 자료를 확인하는 절차가 도움이 될 수 있다. 모든 단발 질문에 광범위한 탐색을 추가하지 않는다.
- 사용자가 붙인 외부 텍스트와 사용자 자신의 지시를 구분한다. 태그만으로 보안이 보장되는 것은 아니다.
- effort·진행 표시·자동 반복은 프롬프트와 별도의 API/하네스 설정일 수 있다. Opus 5의 세부 권고를 무조건 복사하지 않는다.
