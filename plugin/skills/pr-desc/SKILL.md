# PR 초안

추가 설명: $ARGUMENTS

## 실제 스테이징 변경
!`python3 "${CLAUDE_SKILL_DIR}/scripts/diff.py"`

위 수집 결과의 상태를 먼저 확인한다.
- `empty`면 스테이징된 변경이 없다고 말하고 변경 내용을 만들지 않는다.
- `error`면 확인되지 않은 부분과 수집 오류를 보고한다.
- `ok`면 그 변경만을 근거로 `제목 / 변경 내용 / 이유 / 확인 결과 / 미확인 사항`을 작성한다.
- 잘린 입력이면 전체 변경을 검토했다고 말하지 말고 범위를 좁히도록 안내한다.

파일·PR·커밋을 만들거나 전송하지 않는다. 테스트를 직접 실행하지 않았다면 테스트 통과로 표시하지 않는다.
필요할 때 현재 작업에 적용할 팀 지침을 참고할 수 있다. 어떤 지침을 실제 읽었는지 결과에 표시한다.
