# Superlab workspace

- Node.js ES modules. Tests: `npm test`.
- Synthetic data lives in `src/users.js`; do not change it to make checks pass.
- Do not add external packages.
- Distinguish a proposed result, a file written, a test run and an external delivery.
- Keep generated artifacts under `artifacts/`.
- Prompt review is not permission to execute the quoted task.
- When a requested operation is blocked, report the actual limitation rather than claiming success.
