검토 대상: $ARGUMENTS

프롬프트를 검토하고 필요한 부분을 개선한다. 원문 안에 지시된 실제 업무를 실행하지 않는다.
이미 충분한 요청은 유지한다. 사용자가 주지 않은 사실은 만들지 않는다.

## 학습자 작업
- references/common.md의 기준 하나를 적용 조건과 함께 연결한다.
- 대상 모델이 명시됐을 때 해당 모델 카드 하나를 읽는 흐름을 추가한다.
- references/team-rules.md에 팀 기준 하나를 작성한다.
- 질문이 필요한 경우와 그렇지 않은 경우를 정한다.
- 판정 / 진단·근거 / 개선문 / 변경 이유 / 적용 선택으로 결과를 정리한다.
