# 검증 범위

확인일: 2026-10-04

## 구현

- 독립된 세 랩, 참가자 워크시트, 요청받은 제작·실행을 돕는 workshop-coach.
- Lab 1의 기존 스킬 변형과 신규 스킬 제작 재료.
- Lab 2의 공용·로컬 공통 업무 API, 일반 HTTP 클라이언트, 참가자별 데이터 분리.
- Lab 3의 제공 prompt-coach, 원본·개선본 실행과 실제 CLI 사용량 비교, 저장 지시문 점검·공유 재료.
- AWS CloudFormation 생성기와 토큰 발급 도구. 실제 배포는 별도 확인 단계.

## 확인한 것

- Python 3.12.13에서 자동 검사 24개 통과.
- 실제 로컬 HTTP의 인증·계정 분리·입력 검사·신청·재조회·중복·동시성·호출 제한.
- 새 작업 공간, 기존 작업 보존, 토큰 파일 보호, 가상환경 재진입, 비교 결과와 현재 파일의 일치.
- Lambda 이벤트 어댑터가 동일한 업무 계약을 사용하는지 로컬 저장소로 확인.
- AWS validate-template 통과. 필요한 capability: CAPABILITY_IAM.
- 실제 Claude에서 스킬 제작·호출·수정·재실행, 제공 prompt-coach의 개선문 저장과 prompt-audit 확인.
- 실제 학습자 스킬로 필수 조회 4건 → 상신 201 → ID 재조회 200을 확인.
- 필수 조회를 거부한 경우 수정된 스킬이 POST하지 않고 멈추는 것을 확인.
- 같은 모델·medium effort에서 원본·개선본의 실제 출력 및 사용량 기록 확인.
- 제공 지시문의 결함 수정·README 작성 후, 공유 제외 항목을 확인하고 로컬 연습 저장소에 커밋.

## 관찰의 한계

- 템플릿 검증은 AWS 배포나 실제 DynamoDB/API Gateway 동작의 증거가 아닙니다.
- 모델 출력이 형식에 맞아도 사실 판단에 오류가 있을 수 있습니다. 자동 품질 점수를 부여하지 않습니다.
- 비대화형 파일 작성에는 승인 처리 방법이 필요하며, 일반 참가자는 환경의 승인 창에서 판단합니다.
- 실제 교실 전체 동시 사용, 다른 OS·인증 환경, 공용 API 배포 후의 경로는 별도 리허설 대상입니다.
- 상세 실제 응답·토큰·측정 기록·원본 강사용 교안은 공개 저장소에서 제외합니다.
