## 해석 범위

위 결과는 기능 확인이며 통계적 모델 성능 벤치마크가 아닙니다. 모델별 모든 조합·CLI 버전·동시 수강 환경을 보장하지 않습니다.

실제 Slack webhook은 사용하지 않았습니다. 기본 구현은 로컬 mock이며, 강사는 허용된 실습 채널에서 실제 도착을 별도로 확인해야 합니다.

MCP 승인 UI의 사용자 선택과 대규모 동시 수강 부하는 현장 리허설 대상입니다. 비대화형 세션에서 승인이 필요한 신청이 거절되고 서버 상태가 바뀌지 않는 것은 확인했습니다.

실제 모델 응답·실행 로그·원본 강사용 교안·인증정보는 이 공개 저장소에 포함하지 않습니다.
