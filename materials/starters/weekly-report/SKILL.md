우리 팀에 맞춰 바꿀 곳: 독자·필수 항목·보고 기간과 supporting template.
별도 요청이 없으면 한국어로 작성한다. 사용자가 지정한 출력 경로가 있으면 우선한다.

입력: $ARGUMENTS

1. 보고 기간과 자료 파일을 확인한다. 없으면 확인하고 임의의 주차를 선택하지 않는다.
2. 실제 상태 자료와 이 스킬의 `templates/weekly.md`를 읽는다.
3. 업데이트 날짜와 명시된 상태를 근거로 분류한다. 기간 밖의 업무는 제외하거나 별도로 표시한다.
   updated_at은 상태 확인·갱신일이지 실제 완료일이 아니다. 별도 완료일이 없으면 ‘완료 상태 확인일’로 표시하고 실제 완료일은 미확인으로 남긴다.
4. 계획이나 회의에서 정한 업무를 완료한 것으로 바꾸지 않는다.
5. 담당자·완료일·차단 원인이 없으면 미정/미확인으로 표시한다.
6. 입력의 식별자 또는 줄을 근거로 남긴다.

결과를 `artifacts/weekly-report.md`에 작성한다. 외부 게시·전송은 이 스킬의 범위가 아니다.
