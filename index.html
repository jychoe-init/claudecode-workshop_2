준비

Python 3.10 이상, Git, 인증된 Claude Code 2.1.283 이상을 준비합니다. 현재 페이지는 검토용 3랩 브랜치 안내입니다.

터미널 · 새 키트 준비
git clone --branch ch4-three-labs-api https://github.com/jychoe-init/claudecode-workshop_2.git
cd claudecode-workshop_2
bash setup.sh

코치는 기준과 예측을 대신 정하지 않습니다. 참가자가 명시적으로 요청하면 현재 단계의 파일 작성과 실행도 돕습니다. 입력·결과·관찰은 각 폴더의 worksheet.md에 남깁니다.

LAB 1 · 20분 초안

반복업무를 우리 팀 양식으로

기존 회의록·주간보고를 바꾸는 길 A, 자신의 반복업무용 스킬을 새로 만드는 길 B 중 하나를 선택합니다.

결정누가 읽는가, 어떤 항목이 필요한가, 미정 값과 근거를 어떻게 표시하는가.
제작자기 말로 요청하고 양식과 스킬 지시문을 만듭니다.
실행·확인다른 입력 또는 바꾼 양식으로 다시 실행해 재사용을 확인합니다.
터미널 · 새 작업 공간
.venv/bin/python workshop.py init lab1 --root workspaces/lab1
.venv/bin/python workshop.py run --workspace workspaces/lab1
Claude 입력창
/workshop:workshop-coach lab1

가져갈 것: 우리 팀 양식과 판단 기준이 담긴 스킬.

LAB 2 · 20분 초안

API를 통한 업무 자동화

조회에서 끝내지 않고 휴가 신청의 조건 판단·질문·상신·상태 확인까지 처리하는 스킬을 만듭니다.

결정신청 전 조회할 정보, 질문·내용 확인 조건, 실패·중복·응답 끊김 처리.
제작API 명세와 공통 HTTP 클라이언트를 사용해 업무 절차를 스킬에 구현합니다.
실행·확인상신 ID로 재조회하고, 실패 또는 중복 사례에서 실제 기록을 확인합니다.
터미널 1 · 로컬 대체 API
.venv/bin/python workshop.py serve --state .local/api
터미널 2 · 로컬 실습 연결
.venv/bin/python workshop.py init lab2 --root workspaces/lab2
.venv/bin/python workshop.py configure --workspace workspaces/lab2 --local-demo
.venv/bin/python workshop.py run --workspace workspaces/lab2
Claude 입력창
/workshop:workshop-coach lab2

공용 API를 사용할 때는 README의 주소·토큰 등록 절차를 따릅니다. 토큰은 Claude에 붙여넣지 않습니다. 모든 데이터는 가상이고 pending은 상신 상태입니다.

가져갈 것: 실제 실습 API의 업무를 처리하고 결과를 확인하는 스킬.

LAB 3 · 18분 초안

프롬프트 점검·공유

제공 prompt-coach로 자신의 요청을 개선하고, 실제 결과·사용량과 저장 지시문을 점검합니다.

기준좋은 결과의 조건과 유지할 의도를 정합니다.
비교원본과 개선본을 같은 입력·모델의 새 세션에서 실행합니다.
점검·공유지시문 결함을 고치고 README 핵심 세 줄·gitignore·커밋을 준비합니다.
터미널 · 새 작업 공간
.venv/bin/python workshop.py init lab3 --root workspaces/lab3
.venv/bin/python workshop.py run --workspace workspaces/lab3
Claude 입력창
/workshop:workshop-coach lab3

응답 글자 수를 토큰이나 비용으로 대체하지 않습니다. 캐시·모델 조건을 함께 보고, 코치 비용을 별도 측정하지 않았다면 미측정으로 표시합니다.

가져갈 것: 개선 근거, 실제 비교 기록, 사용 안내와 커밋.

기억할 네 가지

Repeat내 기준이 들어간 반복업무 스킬
ConnectAPI를 통한 실제 업무 처리
Prompt원본·개선본의 실제 실행 비교
Inspect · Share검토한 지시문과 재사용 안내
