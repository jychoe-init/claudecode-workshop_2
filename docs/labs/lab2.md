# Lab 2 — API를 통한 업무 자동화

편성 초안 20분. 가상 휴가 신청의 조회·판단·질문·상신·상태 확인을 스킬로 만듭니다.
Slack 연동은 사용하지 않습니다. 이 폴더의 `API.md`가 업무 API 명세입니다.

Claude 입력창:

```text
/workshop:workshop-coach lab2
```

토큰은 Claude에 입력하지 않습니다. 키트 루트의 터미널에서 `workshop.py configure`로 등록하세요.
공용 API를 쓸 수 없는 경우 README의 로컬 서버·로컬 데모 설정 절차를 사용합니다.

`tools/api.py`는 인증과 HTTP 호출만 처리합니다. 예:

```bash
python3 tools/api.py get /v1/me
```

어떤 정보를 조회하고, 언제 질문하며, 어느 조건에서 신청할지는 직접 정해 스킬에 구현합니다.
스킬의 기본 이름은 `leave-request`이며 호출은 `/my-team:leave-request`입니다.
요청 날짜는 서버 기준일 이후의 평일을 선택하세요. 시작 상태는 가용 휴가 12일입니다.

상신 전에 제출 내용을 확인하고, 성공 후에는 신청 ID로 다시 조회합니다.
중복·일수 부족·정보 부족 중 한 사례도 실행해 예상과 실제 상태를 비교하세요.
`pending`은 상신 상태이며 실제 휴가 승인이 아닙니다.

완료 기준:

- 참가자가 만든 스킬로 상신했고, 실제 API 상태를 다시 조회했다.
- 실패 또는 중복 사례에서 원인을 설명하고 추가 신청 여부를 확인했다.
