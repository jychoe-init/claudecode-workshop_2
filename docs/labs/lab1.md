# Lab 1 — 반복업무를 우리 팀 양식으로

편성 초안 20분. 먼저 기준을 정하고 요청하면 Claude가 필요한 파일을 작성합니다.

Claude 입력창에서 시작:

```text
/workshop:workshop-coach lab1
```

길 A는 `materials/starters/`의 회의록·주간보고 시작본을 우리 팀 양식으로 바꿉니다.
길 B는 자신의 반복업무용 스킬을 새로 만듭니다.
어느 길이든 결과를 읽는 사람, 필수 항목, 근거·미정 값의 처리 기준은 직접 정하세요.

학습자 스킬은 `learner-plugin/skills/`에 만듭니다. 처음에는 비어 있습니다.
길 A의 자료는 시작 재료이며 최종 정답이 아닙니다.
양식과 스킬 지시문을 바꾼 뒤 직접 만든 `/my-team:스킬이름`을 호출하세요.
새 스킬을 만든 경우 실행기를 다시 시작해 최신 파일을 로드합니다.

`worksheet.md`에 예상 결과와 실제 출력을 남깁니다.
다른 입력이나 수정된 양식으로 다시 실행해야 재사용 여부를 확인할 수 있습니다.
“힌트”, “만들어줘”, “실행해줘”, “확인해줘”, “다음”처럼 자연어로 진행할 수 있습니다.

완료 기준:

- 팀 기준을 반영한 스킬·양식이 있고 실제 호출 출처를 확인했다.
- 두 실행 결과를 원문과 비교하고 기준 수정 또는 재사용 결과를 설명했다.
