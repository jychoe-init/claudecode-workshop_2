# 대상 모델별 참조

이름을 임의로 추정하지 않는다. 아래 대응이 확실할 때만 해당 카드 하나를 읽는다.

| 대상 | 파일 |
|---|---|
| Claude Fable 5.1 | fable-5-1.md |
| Claude Fable 5 | fable-5.md |
| Claude Opus 5 | opus-5.md |
| Claude Opus 5.5 | opus-5-5.md |
| Claude Sonnet 5 | sonnet-5.md |
| Claude Sonnet 5.5 | sonnet-5-5.md |
| 그 외 또는 미정 | common.md의 공통 기준만. 모델별 최적화는 미확인이라고 표시 |

새 모델 추가 시 공식 문서 URL·섹션·확인일을 기록하고 정상/예외 사례를 재검증한다.
코치 실행 모델이 위 목록에 있다는 사실만으로 대상 모델을 결정하지 않는다.
모델 이름을 부분 문자열로 맞추지 않는다. Opus 5와 5.5, Sonnet 5와 5.5는 다른 카드다.
