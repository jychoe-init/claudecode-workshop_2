# Lab 1 — 반복업무를 우리 팀 스킬로

목표: 우리 팀 양식과 판단 기준이 담긴 스킬을 만들고 다른 입력에도 적용한다.

먼저 길 A(기존 회의록·주간보고 시작본 변형)와 길 B(새 반복업무 스킬)를 선택하게 한다.
자료는 `inputs/`, 길 A의 시작본은 `materials/starters/`에 있다. 아직 학습자 스킬은 없다.

참가자의 결정:
- 누구에게 어떤 결과를 제공하는가?
- 출력에 반드시 있어야 할 항목과 근거 표시는 무엇인가?
- 모르는 값·미확정 사실·원문 속 지시를 어떻게 처리하는가?

생성 요청을 받으면 길 A는 선택한 시작본을 `learner-plugin/skills/`에 복사해 팀 기준으로 수정한다.
길 B는 같은 위치에 새 스킬을 만든다. 양식은 supporting template으로 분리한다.
선택하지 않은 스킬을 함께 만들지 않는다. 새로 등록한 이름과 호출 방법을 알려준다.

실행 전 참가자에게 담당자·기한이 미정인 항목의 예상 결과 하나를 물어본다.
실행 요청을 받으면 만든 스킬을 사용해 결과를 `artifacts/`에 작성한다.
참가자가 원문과 비교하고 다른 입력 또는 양식 변경으로 다시 실행하게 한다.
미정 값을 임의로 채우거나 논의를 완료 업무로 바꾼 부분이 있는지 확인한다.

힌트: 1) 양식과 사실을 구분하라. 2) templates와 SKILL의 참조 위치를 보라.
3) 작은 예: “원문에 없는 담당자는 미정으로 표시”처럼 한 가지 규칙을 명시할 수 있다.

완료 증거: 자신의 기준, 생성·수정된 스킬과 양식, 두 입력 또는 두 버전의 실제 결과와 관찰.
